# ADR-0002: Η τράπεζα ερωτήσεων παράγεται από script, δεν γράφεται στο χέρι

- Κατάσταση: Accepted
- Ημερομηνία: 2026-09-01
- Πλήρες σκεπτικό: engineering log §3, §4
- Σημείωση: γράφτηκε αναδρομικά στις 2026-09-07

## Πλαίσιο

Η εφαρμογή χρειάζεται χιλιάδες ερωτήσεις, οργανωμένες ανά τάξη Δημοτικού και
ανά μάθημα. Μεγάλο μέρος τους είναι παραλλαγές πάνω σε λίγα πρότυπα:
αριθμητικές πράξεις, κλίση ρημάτων σε χρόνους, ορθογραφικά κενά, προβλήματα με
αντικείμενα και ποσότητες.

Δύο τρόποι υπάρχουν να ζήσει αυτό το περιεχόμενο. Είτε το JSON είναι η πηγή και
γράφεται/επεξεργάζεται απευθείας, είτε πηγή είναι ένα script που το παράγει.

Το κρίσιμο στοιχείο δεν είναι ο όγκος αλλά η **ομοιομορφία των κανόνων**: μια
απαίτηση ποιότητας — «οι απαντήσεις ρημάτων σε α' ενικό», «τόσες παύλες όσα τα
γράμματα που λείπουν», «τα αντικείμενα των προβλημάτων μόνο σε ουδέτερο
πληθυντικό ώστε το ‘Πόσα …’ να στέκει πάντα» — δεν αφορά μία ερώτηση αλλά κάθε
ερώτηση της ίδιας οικογένειας. Με πηγή το JSON, κάθε τέτοια απαίτηση είναι
μαζική αναζήτηση-και-αντικατάσταση με χειροκίνητο έλεγχο.

## Απόφαση

Πηγή αλήθειας για το περιεχόμενο είναι το script `scripts/generate-questions.mjs`.
Τα αρχεία `src/data/questions-{a..f}.json` είναι **παραγόμενα** και δεν
επεξεργάζονται ποτέ χειροκίνητα.

Η παραγωγή είναι ντετερμινιστική: χρησιμοποιεί seeded RNG με σταθερό seed, ώστε
δύο εκτελέσεις να δίνουν πανομοιότυπα αρχεία και το diff να δείχνει μόνο ό,τι
πραγματικά άλλαξε.

Ο κύκλος αλλαγής περιεχομένου είναι: επεξεργασία του script → εκτέλεσή του →
**commit του script και των παραγόμενων JSON μαζί, στο ίδιο commit**.

Οι ερωτήσεις που γράφονται στο χέρι (π.χ. Μελέτης Περιβάλλοντος, Ιστορίας)
γράφονται **μέσα στο script**, σε πίνακες δεδομένων, όχι στο JSON.

Κάθε ερώτηση παίρνει δομημένο id της μορφής
`<γράμμα τάξης>-<γράμμα κατηγορίας><αύξων αριθμός>`, με τα γράμματα κατηγορίας
επιλεγμένα ώστε να μη συγκρούονται μεταξύ κατηγοριών με ίδιο αρχικό.

## Συνέπειες

Ένας κανόνας ποιότητας εφαρμόζεται παντού με μία αλλαγή, και μια διόρθωση
γίνεται στην αιτία αντί στο σύμπτωμα. Αυτό έχει ήδη αποδειχθεί σε πραγματική
διόρθωση bug: όταν βρέθηκε ότι κάποιες γεννήτριες παρήγαγαν αριθμούς αντί για
strings στις επιλογές πολλαπλής επιλογής, η λύση ήταν μία γραμμή στη συνάρτηση
που φτιάχνει τις ερωτήσεις και μια επαναπαραγωγή.

Το κόστος είναι ότι **δεν υπάρχει φθηνή διόρθωση**. Ένα τυπογραφικό σε μία
ερώτηση απαιτεί κατανόηση του σημείου του script που την παράγει. Το script
είναι μεγάλο (πάνω από 3.500 γραμμές) και είναι το μοναδικό σημείο όπου γίνεται
οποιαδήποτε δουλειά περιεχομένου.

Επειδή τα ids είναι αύξοντες αριθμοί ανά κατηγορία, μια αλλαγή που **προσθέτει
ή αφαιρεί** ερωτήσεις μετατοπίζει τα ids όσων ακολουθούν. Τα ids αυτά
χρησιμοποιούνται ως κλειδιά για την ανά-ερώτηση ανατροφοδότηση χρηστών που
αποθηκεύεται στο cloud — άρα η αντιστοίχιση παλιάς ανατροφοδότησης με ερωτήσεις
δεν επιβιώνει εγγυημένα μια τέτοια αλλαγή. Οποιαδήποτε αναδιάταξη περιεχομένου
πρέπει να το λαμβάνει υπόψη ρητά.

Το script είναι απλό JavaScript και **δεν** ελέγχεται από τον type checker του
project, ενώ ο κώδικας που καταναλώνει τα JSON τα δέχεται με cast. Άρα καμία
βαθμίδα του build δεν επιβεβαιώνει ότι το παραγόμενο περιεχόμενο ταιριάζει με
τον τύπο που η εφαρμογή περιμένει. Αυτό είναι πραγματικό κενό, όχι θεωρητικό:
έχει ήδη βγει ζωντανά ως κόλλημα της εφαρμογής σε πάτημα απάντησης.

Η ντετερμινιστικότητα εξαρτάται από το σταθερό seed **και από τη σειρά κλήσης**
των γεννητριών: μια αλλαγή στη σειρά αναδιατάσσει τα πάντα μετά από αυτήν, με
τεράστιο και δυσανάγνωστο diff, ακόμα κι αν το περιεχόμενο είναι ισοδύναμο.
